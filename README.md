# Bucketlist – Lab 2 PHP

## Om projektet

Detta projekt är en webbplats där användaren kan skapa och hantera en personlig bucketlist.

Webbplatsen utvecklas med:

- HTML
- CSS
- PHP
- MySQL/MariaDB
- Objektorienterad programmering

## Funktioner

- Visa bucketlist
- Lägga till aktiviteter
- Radera aktiviteter
- Information om projektet
- Redovisning av AI-användning

## Installation

Projektet använder PHP och MySQL/MariaDB. En installationsfil används för att skapa databastabellen.
