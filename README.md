# Bucketlist – Lab 2 PHP

## Om projektet

Detta projekt är en webbplats där användaren kan skapa och hantera en personlig bucketlist med saker som man vill göra och uppleva under sin livstid.

Webbplatsen är utvecklad med:

- HTML
- CSS
- PHP
- MySQL/MariaDB
- Objektorienterad programmering

## Funktioner

- Visa alla aktiviteter i bucketlistan.
- Lägga till nya aktiviteter.
- Radera aktiviteter.
- Ange beskrivning och prioritet för aktiviteter.
- Visa datum då aktiviteterna lades till.
- Information om projektet och reflektioner kring PHP.
- Redovisning av AI-användning.

## Filstruktur

- `css/` – Webbplatsens CSS.
- `diagrams/` – ER-diagram och UML-diagram.
- `includes/` – PHP-klasser och gemensamma filer.
- `index.php` – Startsida.
- `bucketlist.php` – Hantering av bucketlistan.
- `ai.php` – Redovisning av AI-användning.
- `install.php` – Skapar databas och tabell.

## Installation

Projektet kräver en webbserver med PHP och MySQL/MariaDB.

1. Ladda ner eller klona projektet.
2. Placera projektmappen i webbserverns katalog.
3. Kontrollera databasuppgifterna i PHP-filerna.
4. Öppna `install.php` i webbläsaren för att skapa databasen och tabellen.
5. Öppna `index.php` för att använda webbplatsen.

Databasen heter `bucketlist` och tabellen heter `items`.
